Логотип и маскот
================

Маскота зовут Vexi. Исходники — четыре PNG в assets/vexi-src (вне public
намеренно: скрипт читает оттуда и пишет сюда, поэтому его можно запускать
сколько угодно раз и кадрирование не «поедет»).

  vexi-purple.png  обычное состояние, подсказки, логотип приложения
  vexi-gray.png    нет аватарки / только что зарегистрировался
  vexi-amber.png   предупреждение
  vexi-red.png     ошибка

Всё остальное собирается из них одной командой:

    pip install pillow
    python scripts/vexi_from_assets.py

Что появится:
  public/vexi/vexi-*.png       512×512, используются от 64px и выше
  public/vexi/vexi-*@128.png   128×128, их подставляет VexiFace для мелких мест
  public/brand-logo.png        логотип: сплеш, титлбар, рельса, логин, Electron
  app/icon.png                 фавикон
  electron/icon.png            иконка сборки (.exe / .dmg)
  electron/tray*.png           трей, включая macOS-template (только альфа)

Поменять рисунок — заменить файл в assets/vexi-src и перезапустить скрипт.
Править PNG в public бессмысленно: следующий запуск их перезапишет.

Запасной SVG-силуэт в components/BrandMark.tsx рисуется только если PNG не
отдался. С растровым исходником он совпадает приблизительно — это нормально.
